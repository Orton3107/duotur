# TürkçeYol

PWA для изучения турецкого языка (аналог Duolingo, без озвучки). React + TypeScript + Vite + Tailwind, прогресс — в PocketBase.

Модули: Путешествия, Работа, Семья, Отношения, Друзья — 352 слова/фразы бытовой лексики, разбитые на уроки по 8 слов. Каждое слово встречается в уроке дважды: сначала лёгкое упражнение на узнавание (выбор перевода), затем более сложное — выбор турецкого слова, сборка фразы/слова из тайлов или ввод с клавиатуры.

## Разработка

```bash
npm install
npm run dev
```

Приложение работает полностью офлайн на localStorage — аккаунт и PocketBase не обязательны для использования.

## PocketBase (облачная синхронизация прогресса)

1. Скачайте PocketBase (https://pocketbase.io/docs/) и запустите:
   ```bash
   ./pocketbase serve
   ```
2. Откройте `http://127.0.0.1:8090/_/`, создайте супер-пользователя (первый запуск попросит это сделать).
3. Создайте коллекции и поля запуском скрипта (добавляет `xp`, `streak`, `last_active` в `users` и создаёт `user_progress`):
   ```bash
   PB_URL=http://127.0.0.1:8090 PB_SUPERUSER_EMAIL=you@example.com PB_SUPERUSER_PASSWORD=yourpassword npm run pb:setup
   ```
4. Создайте `.env` в корне проекта (см. `.env.example`):
   ```
   VITE_POCKETBASE_URL=http://127.0.0.1:8090
   ```
5. Перезапустите `npm run dev`. Теперь регистрация/вход в приложении будет сохранять прогресс в PocketBase; без бэкенда приложение продолжает работать локально (запросы к серверу тихо игнорируются при недоступности).

## Сборка и установка на телефон (Add to Home Screen)

```bash
npm run build
npm run preview -- --host
```

PWA (манифест + service worker) корректно работает только по HTTPS (или на `localhost`). Для реального телефона задеплойте `dist/` на любой статический хостинг с HTTPS (Netlify, Vercel, Cloudflare Pages и т.п.) — там уже лежит `public/_redirects` для SPA-роутинга на Netlify.

- **Android (Chrome):** откройте сайт → меню (⋮) → «Установить приложение» / «Добавить на главный экран».
- **iOS (Safari):** откройте сайт → кнопка «Поделиться» → «На экран «Домой»».

## Иконки

Иконки в `public/icons/` сгенерированы скриптом `npm run gen:icons` (`scripts/generate-icons.mjs`, использует `sharp`). Чтобы поменять дизайн иконки — отредактируйте SVG в этом файле и запустите скрипт заново.

## Структура контента

- `src/data/words/*.ts` — словари по модулям (модуль → массив `{id, tr, ru, pos}`)
- `src/data/lessons.ts` — нарезка слов на уроки по 8 штук
- `src/engine/exerciseGenerator.ts` — генерация упражнений для урока
